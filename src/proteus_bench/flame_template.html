Reading it

Each box is a function. Width is the share of CPU samples spent in it and everything it called. Stacks grow upward from the root. Click a box to zoom in; hover for exact numbers. Colour marks the component.

  • Aragog
  • Zalmoxis (hatched)
  • PROTEUS
  • other Python (MORS, CALLIOPE, ...)
  • native code: Julia (AGNI, JIT; hatched)
  • native code: interpreter, numpy/scipy, libc

Method and caveats

Built from folded stacks (stacks.folded.gz next to this page). Consecutive native frames are merged into one block. Widths are shares of samples under profiling, which inflates Python-heavy code more than native code; they are not minutes of a plain run. Measure phase durations with the run's timing record and use this page for what is hot inside a phase. JIT-compiled JAX kernels are opaque to the profiler.
